We need several well-designed, efficient and effective probes to help examine the model status, behavior and performance. Below are the examples of probes I can give you, get inspired but do not be limited to the example. Note: try not overly focus/think on just the attribute/dataset head(s),

1. Concept Probes Description: Concept probes (e.g., Concept Activation Vectors, CAVs) map model internals to human-understandable concepts. They work by defining a direction in representation space that corresponds to a concept (like “sports” or “violence”), then testing how much model predictions are influenced by that concept. Example: For an image classifier, a concept probe could test if the model’s prediction of “dog” is overly influenced by the presence of “grass.” If grass activation strongly drives the prediction, it reveals potential spurious correlation.

2. Causality Probes Description: These probes intervene on specific internal representations of a model (e.g., embeddings of a property) and measure how predictions change. They assess whether the model relies causally on that property. Example: In a text classifier for movie reviews, you could modify the embedding for “!” (exclamation marks) to see if it disproportionately flips predictions from neutral to positive. This tests if punctuation, not content, drives sentiment.

3. Bias Probes Description: Bias probes detect if social stereotypes or systematic biases are encoded in the model. They evaluate model outputs or internals under controlled input variations related to sensitive groups. Example: For a resume screening model, provide identical resumes with only the name switched from “John” to “Jamila.” If the model changes its prediction, the probe exposes bias linked to names as proxies for gender/ethnicity.

4. Data Probes Description: Data probes test model behavior by deliberately designing small but diverse datasets that highlight edge cases or unusual patterns. They help surface blind spots and limitations. Example: For a chatbot, construct a probe dataset with polite but indirect requests (“It’s a bit chilly here”) to see if the model fails to interpret them as a request for “turning up the heat.”

5. Commonsense Probes Description: These evaluate whether the model encodes everyday world knowledge. They check if the model can reason about physical, social, or causal facts that humans usually take for granted. Example: Ask a QA model: “How many legs does a bird have?” If the model answers “four,” the probe reveals a commonsense gap.
